# Singulink.Threading

## Overview

**Singulink.Threading** is a small utility library of locks and lock-free helpers for multithreaded and async code. The [README on GitHub](https://github.com/Singulink/Singulink.Threading#usage) shows each type in use and helps you choose a lock.

This package is part of our **Singulink Libraries** collection. Visit https://github.com/Singulink to see our full list of publicly available libraries and other open-source projects.

## Installation

The package is available on NuGet - simply install the `Singulink.Threading` package.

**Supported Runtimes**: .NET 10.0+
